## Anston Sorensen

Electrical Engineering student at the University of Florida (B.S. expected 2029, Business Administration minor). I like building where hardware meets software: emulators, server infrastructure, embedded systems, and the pipelines that build and ship them.

### Projects

- **[VM Computers](https://github.com/AC-Clash/MCVmComputers-Spigot)**: runs real QEMU virtual machines inside vanilla Minecraft, painting the guest's screen onto in-game maps. Java 21, Gradle, Spigot API.
- **[AC-Clash](https://github.com/AC-Clash)**: a Minecraft server network I run on a 4-machine Ubuntu Server cluster, with custom Java plugins and a [reusable GitHub Actions release workflow](https://github.com/AC-Clash/workflows) that builds, tags, and publishes every plugin.
- **[Perk General Contracting](https://github.com/Aura-Concepts/perk-general-contracting)**: website I designed and built for a local contractor through my business, [Aura Concepts](https://auraconcepts.co). Pushes to GitHub deploy automatically to Cloudflare.
- **[jDOSBox](https://github.com/Tennessene/jDOSBox)**: maintaining a continuation of a Java x86 emulator based on DOSBox.
- **[ASHER](https://github.com/Tennessene/asher)**: Raspberry Pi replacement for a broken treadmill display, reading belt rotations over GPIO to calculate speed, distance, and pace.
- **Florida Rocket Lab**: designed a 2-layer flight computer PCB in Altium and wrote C++ telemetry simulation software for a thrust-vector-controlled rocket.

### Tools

C++, Java, C#, Python, Linux (Ubuntu Server), shell scripting, Jenkins, Nexus, Git, GitHub Actions, Gradle, Altium, AutoCAD
